##  Sobre o projeto

Portfólio pessoal desenvolvido com HTML5 e CSS3 puro, sem frameworks ou JavaScript. O objetivo foi criar uma página profissional, organizada e responsiva para apresentar minha trajetória, habilidades e projetos.

##  Seções

- **Apresentação** — nome, avatar e frase de abertura
- **Sobre mim** — formação, área de interesse e motivações
- **Habilidades** — tecnologias e ferramentas que estou aprendendo
- **Projetos** — trabalhos desenvolvidos durante o curso
- **Contato** — e-mail, GitHub e LinkedIn

##  Tecnologias utilizadas

- HTML5 (semântico)
- CSS3 (Flexbox, Grid, Media Queries)
- Google Fonts (DM Sans + DM Serif Display)
- Font Awesome (ícones)

##  Responsividade

O site é totalmente responsivo, adaptando o layout para dispositivos móveis, tablets e desktops por meio de unidades relativas (`rem`, `%`) e media queries.
